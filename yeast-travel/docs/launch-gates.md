# Yeast Travel launch gates

## Content gate

- [x] Four cities and 12 researched day modules exist.
- [x] At least 36 bilingual stops have an official or authoritative source.
- [x] Every stop names timing, booking risk, fallback and last-checked date.
- [ ] Weekday field walk completed for each launch route.
- [ ] Weekend crowd and pacing walk completed.
- [ ] Rain or closure fallback physically tested.
- [ ] Foreign-passport reservation flow tested where required.
- [ ] Missing GCJ-02 visitor entrances resolved for Tongli, Gaoling and Dongbu.

## Product gate

- [x] City + days + two-interest limit works without an account.
- [x] Stable 1–3 day plan URLs are generated.
- [x] Chinese addresses remain readable when maps fail.
- [x] Side Quest cannot be purchased while unverified.
- [ ] Interest-specific stop substitutions researched and approved. Until then, interests are saved but the route remains fixed.
- [ ] Five foreign residents or recent visitors complete unmoderated testing.

## Commercial gate

- [x] Affiliate and partner disclosure language exists.
- [x] Route-interest form does not authorise transfer to an unnamed supplier.
- [ ] At least four offers have a named licensed fulfiller, English delivery, current cancellation rule and traceable attribution.
- [ ] Professional review confirms the information-platform, affiliate and lead-transfer boundary.
- [ ] Operator identity, retention period, governing law and contact address are added to legal pages.

## Technical gate

- [x] Static Astro build and sitemap succeed.
- [x] Amap has a no-key/no-script fallback and never requests geolocation.
- [x] Analytics is optional and carries no contact information.
- [x] Netlify forms are present in generated static HTML.
- [ ] Production domain, DNS and `SITE_URL` configured.
- [ ] Amap web key, security code and domain allowlist configured.
- [ ] Netlify Forms enabled, notification recipient configured and end-to-end submissions received.
- [ ] Plausible domain configured and five funnel events verified.

## Growth proof

- [ ] 100 qualified visitors.
- [ ] 30 generated plans.
- [ ] 40% map-open rate.
- [ ] 15 paid-offer clicks or valid leads.
- [ ] 10 paid users verified by order ID, supplier confirmation or dedicated code.

Clicks alone do not count as paid users.
